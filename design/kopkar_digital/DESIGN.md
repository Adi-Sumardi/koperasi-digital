## Brand & Style

This design system establishes a trustworthy, transparent, and approachable digital financial ecosystem for modern Indonesian Employee Cooperatives (Koperasi Karyawan). Built to bridge mutual enterprise values (*gotong royong*) with contemporary fintech reliability, the visual environment rejects clutter and archaic bureaucratic friction in favor of crisp financial transparency, ergonomic speed, and institutional stability.

The style fuses **Corporate / Modern** fintech precision with soft human-centric touches. Crisp white structural canvases are framed by deep ocean sapphire foundations and energized by electric cobalt accents. Information is structured to reduce cognitive fatigue during rapid loan reviews, SHU (Sisa Hasil Usaha) dividend checks, voluntary savings management (*simpanan sukarela*), and cooperative store voucher redemptions. The resulting emotional signature is reassuring, organized, dignified, and distinctly member-focused.

## Colors

The palette is rooted in institutional trust, financial dynamism, and high-legibility ergonomics tailored for outdoor and indoor workplace settings.

### Core Roles
- **Primary (`#1D4ED8`)**: The bedrock sapphire tone. Used for dominant action buttons, active navigation markers, key financial card backdrops, and verified institutional badges.
- **Secondary (`#2563EB`)**: Electric cobalt blue. Injects modern fintech vitality; utilized for active states, link actions, positive trend highlights, and interactive toggles.
- **Tertiary (`#DBEAFE`)**: Soft ice blue. Supplies a gentle container background for badges, selected chip items, and secondary alert banners without creating visual glare.
- **Neutral Dark (`#0F172A`)**: Slate navy. Replaces pure black to deliver deep contrast, high-end editorial clarity, and reduced eye strain for numbers, metrics, and typographic headers.

### Supporting Contextual Swatches
- **Surface Canvas**: `#FFFFFF` for primary cards, sheets, and dialogs; `#F8FAFC` for page canvases and grouped segment wells.
- **Border / Divider**: `#E2E8F0` for subtle card boundaries and input borders.
- **Financial Status Accents**:
  - *Active / Paid / Verified*: Emerald (`#059669` fill, `#D1FAE5` container)
  - *Pending / In Review*: Amber (`#D97706` fill, `#FEF3C7` container)
  - *Delinquent / Rejected / Critical*: Crimson (`#DC2626` fill, `#FEE2E2` container)

## Typography

Typography prioritizes clarity, numerical balance, and rapid visual scanning. 

- **Display & Headings (Plus Jakarta Sans)**: Used for titles, section headings, and warm conversational copy. It introduces a modern, friendly Indonesian geometric cadence while remaining authoritative.
- **Labels & Financial Data (Inter)**: Applied to table figures, ID numbers (Nomor Anggota Koperasi), currency metrics (Indonesian Rupiah formatting `Rp xx.xxx.xxx`), and small badges. Inter's tabular numbers and crisp geometry prevent alignment drift across multi-tier balance breakdowns.

## Layout & Spacing

The layout utilizes an 8-point base grid system combined with safe dynamic horizontal paddings tailored specifically for compact single-hand mobile interactions.

### Form Factors & Adapters
- **Mobile Handheld (< 480px)**: Primary operational context. Fixed 16px (`space-md`) side margins ensure structural breathing room, while internal vertical card stacks run at 12px (`space-sm`) gaps. Total column spans default to full width (single-column cards) or equal 2-column action matrices.
- **Tablet / Large Mobile Foldables (481px - 768px)**: Fluid 2-column or 3-column masonry/dashboard grid with 24px margins and gutters.
- **Touch Targets**: All interactive elements (CTA buttons, selection rows, navigation tabs, quick action icons) maintain a hard minimum target of 44px (`tap-target-min`).

### Bottom Clearance
To prevent accidental gesture conflicts and bottom bar overlap, all scrollable root containers require bottom padding equal to `bottom-bar-height` + `space-xl` (6rem / 96px).

## Elevation & Depth

This system avoids heavy, muddy skeuomorphism, relying instead on clean, multi-layered depth where subtle tonal separation meets soft, blue-tinted ambient shadows.

### Elevation Levels
- **Level 0 (Flat Canvas)**: `#F8FAFC` base application container. No shadow. Used behind elevated cards and tab panels.
- **Level 1 (Card & Row Base)**: `#FFFFFF` surface accompanied by a crisp hairline border `1px solid #E2E8F0` and subtle tinted drop shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`.
- **Level 2 (Active Cards & Floating Widgets)**: Used for primary balance cards, floating notification chips, and active dropdown overlays: `0 4px 12px -2px rgba(29, 78, 216, 0.08), 0 2px 6px -2px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Sticky Bottom Bar & Modal Sheets)**: Bottom navigation bar, bottom action sheets, and prompt dialogues: `0 -4px 16px -2px rgba(15, 23, 42, 0.06), 0 -2px 6px -1px rgba(15, 23, 42, 0.03)`.

### Border Discipline
Every card or elevated surface incorporates a `1px` border using `#E2E8F0` or `#DBEAFE` (when highlighted). This guarantees clean optical definition on screens set to varying contrast calibrations.

## Shapes

The design system employs a rounded, contemporary shape grammar that communicates approachability and modern mobile polish without appearing toy-like.

- **Primary Container Shells (`rounded-2xl` / 16px)**: Standard for core financial balance cards, loan status trackers, and dialog overlays.
- **Interactive Controls (`rounded-xl` / 12px)**: Buttons, text fields, search boxes, and list items.
- **Indicator Elements (`rounded-full` / 9999px)**: Status badges (e.g., "Lunas", "Menunggu Persetujuan"), notification counters, avatars, and bottom navigation pill indicators.

## Components

### Buttons
- **Primary**: Background `#1D4ED8`, text `#FFFFFF`, radius `rounded-xl`, vertical padding `14px`, horizontal padding `20px`. Hover/pressed state shifts to `#1E40AF`. Active shadow `0 2px 8px rgba(29, 78, 216, 0.25)`.
- **Secondary / Ghost**: Background `#DBEAFE`, text `#1D4ED8`, zero border. Pressed state drops to `#BFDBFE`.
- **Outline**: Background `#FFFFFF`, border `1.5px solid #E2E8F0`, text `#0F172A`.

### Status Badges & Chips
- Formatted as `rounded-full`, padding `4px 10px`, font `label-sm`.
- **Simpanan Aktif / Approved**: `#D1FAE5` background with `#059669` text.
- **Pengajuan Pinjaman (Pending)**: `#FEF3C7` background with `#B45309` text.
- **Kategori Filter Chip**: Default `#F1F5F9` background, `#475569` text; Active state `#1D4ED8` background, `#FFFFFF` text.

### Financial Summary Cards
- Surfaces feature `rounded-2xl`, background `#FFFFFF` with hairline `#E2E8F0` border and Level 1 elevation.
- Includes a top micro-header showing account or deposit classification (*Simpanan Wajib, Pokok, Sukarela*), numerical metric in `financial-display` typography, and bottom subtext comparing year-to-date dividend (*SHU*) yield.
- High-priority hero balance card may utilize an inverted gradient style (`linear-gradient(135deg, #1D4ED8 0%, #1E40AF 100%)`) with white text and `#DBEAFE` subtext.

### Form Inputs & Selectors
- Standard height `48px`, border `1.5px solid #E2E8F0`, background `#FFFFFF`, border radius `rounded-xl`, text `#0F172A`, placeholder `#94A3B8`.
- Focus state triggers border color `#2563EB` along with a soft electric blue focus ring `0 0 0 3px rgba(37, 99, 235, 0.15)`.
- Prefix addons (such as fixed `Rp` labels) utilize `#F8FAFC` backgrounds with right divider borders.

### Mobile Bottom Navigation Bar
- Fixed to viewport base with height `72px` (`bottom-bar-height`).
- Background `#FFFFFF` with Level 3 top ambient elevation and top border `1px solid #E2E8F0`.
- 4 to 5 navigation items: *Beranda* (Home), *Simpanan* (Savings), *Pinjaman* (Loans), *Toko/Voucher* (Coop Mart), and *Akun* (Profile).
- Active item uses `#1D4ED8` icon fill, accompanied by a subtle 4px dot indicator underneath and bolded `label-sm` text. Inactive items use `#64748B`.
